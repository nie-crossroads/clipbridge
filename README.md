# ClipBridge · 拾影

文档日期：2026-11-18。当前阶段：需求与架构设计、本地数据库初始化已完成，尚未实现新的 Go 服务。

项目及代码仓库名：`clipbridge`。定位：多平台媒体解析服务，支持网页预览、直链下载、开放 API 与 MCP 接入。

服务目标：解析多平台分享链接，提供网页播放与下载、管理后台、开放 API 和 MCP 接入。当前开发数据库使用本地 MySQL `127.0.0.1:3306/clipbridge`；本地构建后部署单个 Go 服务，媒体默认由浏览器直接访问平台 CDN。

## 已确定的主要方向

- Go + Chi + 官方 MCP Go SDK；Vue 3 + TypeScript + Vite + Element Plus。
- 当前使用本地 MySQL 8.0.17，数据库名 `clipbridge`；后续需要时通过配置切换到云端 MySQL。
- 网页、REST API、MCP 共用解析核心，接口之间不通过本站 HTTP 请求相互转发。
- 网页前台公开使用：解析、播放、直链下载和资源切换无需登录；只有管理后台要求管理员登录。
- API 与 MCP 分别生成密钥；按调用方配置权限、平台范围、有效期和限额。
- 网页采用原生 video 播放，默认使用平台直链；代理功能可关闭、单独授权。
- 视频不进入 MySQL；首版不默认保存视频到服务器。
- 前端构建为静态资源，嵌入 Go 程序；应用运行无需常驻 Node.js、PHP 或 Redis。当前本机运行 MySQL，服务器阶段另行确定数据库部署位置。

## 本地配置

数据库地址为 `127.0.0.1:3306`，库名为 `clipbridge`，开发账号为 `root`。连接密码只保存在本地 `.env`，该文件已加入 `.gitignore`；[.env.example](.env.example) 提供无真实密码的配置模板。此处的配置项是后续 Go 服务的约定，尚无应用程序读取它们。
