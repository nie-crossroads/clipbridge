# ClipBridge · 拾影

拾影是多平台媒体解析工具。公开网页接受分享链接或分享文本，解析后可预览媒体、复制直链和下载。前端使用 Vue 3、TypeScript、Vite 和 Element Plus，Go 服务使用 Chi，并将前端产物嵌入二进制。业务配置和记录保存在 MySQL。

## 当前进度

- 公开解析页包含平台列表、浅色和深色主题、移动端布局，以及原生媒体预览和直链操作。
- 视频适配器已接入 B 站、抖音、快手、小红书、微博、今日头条及西瓜视频、皮皮虾、皮皮搞笑、最右、即梦和豆包。解析使用公开分享页或平台作品接口返回的视频源。浏览器可在平台提供备选直链时切换视频源。
- 已用公开作品验证 B 站、抖音、皮皮虾、皮皮搞笑、最右、即梦和豆包能够返回可读取的 MP4。其余平台有响应样例测试，公开链接受匿名访问策略和平台返回格式影响。可在后台通过「解析测试」确认实际可用性。
- 前台播放和复制直链使用平台地址，点击下载视频会在新标签页打开平台直链。
- 后台支持管理员登录、解析测试、平台启停与超时配置、调用与审计查询。可通过分步向导创建 REST 或 MCP 密钥，并查看用量、启停、轮换或撤销。系统设置支持修改前台限速、解析并发、日志保留和前台解析缓存。
- 待实现内容包括网易云音乐音频适配器、B 站多分 P 列表、REST/MCP 调用入口、调用配额执行、平台凭据及媒体代理。

## 本地运行

需要 Go 1.26、Node.js 22.12+ 和 MySQL 8.0+。以仓库根目录为工作目录。使用现有 `.env`，或根据 [.env.example](.env.example) 生成本地配置。环境变量优先于文件。

先选定项目数据库，按顺序执行 [初始迁移](migrations/000001_init.up.sql) 和 [调用来源脱敏字段迁移](migrations/000002_request_source.up.sql)。已有初始表的数据库只需执行尚未应用的迁移。

```powershell
npm --prefix web ci
npm --prefix web run build
go build -o bin/clipbridge.exe ./cmd/server

./bin/clipbridge.exe admin create <用户名>
$env:CLIPBRIDGE_SECURE_COOKIE = 'false'
./bin/clipbridge.exe serve
```

创建管理员时在终端输入密码。首次启动后打开 [管理后台](http://127.0.0.1:8080/admin/login)，通过「解析测试」验证公开作品，再在「平台配置」启用对应平台。启用后可在 [公开解析页](http://127.0.0.1:8080/) 粘贴分享链接。

在本地 `.env` 中设置 `CLIPBRIDGE_LOCAL_ADMIN_USERNAME` 和 `CLIPBRIDGE_LOCAL_ADMIN_PASSWORD` 后，服务每次启动都会检查该管理员的密码。密码有变化时更新哈希并注销该账号的现有会话。此配置要求账号已启用，服务和 MySQL 均通过本机回环地址连接。

本地 HTTP 示例仅监听回环地址。部署到 HTTPS 环境时使用默认的 `CLIPBRIDGE_SECURE_COOKIE=true`。服务提供 `/healthz` 存活检查和 `/readyz` 数据库与建表就绪检查。

修改页面时，可另开终端运行 `npm --prefix web run dev`，Vite 将本地 API 请求转给 `127.0.0.1:8080`。Go 构建和测试前需先生成 `web/dist`。
